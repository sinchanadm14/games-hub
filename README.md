🎮 Mini Games Hub

A collection of 4 interactive mini games built using **HTML, CSS, and JavaScript**.

 🎯 Games Included

* ✊ Rock Paper Scissors
* 🔢 Number Guessing Game
* 🧠 Quiz Game
* ❌⭕ Tic Tac Toe

 🛠️ Technologies Used

* HTML
* CSS
* JavaScript

 ▶️ How to Run

 Method 1 — Using Live Server

1. Download or clone this repository.
2. Open the project folder in **VS Code**.
3. Install the **Live Server** extension if you don't already have it.
4. Right-click on `index.html`.
5. Select **Open with Live Server**.
6. The Mini Games Hub will open in your browser.

### Method 2 — Directly in Browser

1. Download the project.
2. Open the project folder.
3. Double-click `index.html`.
4. The website will open in your default browser.
